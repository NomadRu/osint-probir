Как добавлять новую статью:

1. Копируете article-template.html в папку articles/
2. Переименовываете например в 04-prazdnik-derevni.html
3. Редактируете внутри заголовок, дату и текст
4. Открываете script.js и добавляете одну строчку в массив articles:
   ```js
   { file: ".html", title: " ", date: "00.00.2026" }
   ```
5. Сохраняете — всё, статья появится на главной
